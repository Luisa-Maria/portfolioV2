CLIMA REAL

REACT TAILWIND CSS OPENWEATHER API

Visión General

La aplicacion de clima real es una experiencia que permite a los usuarios consultar el clima de diferentes ciudades. les permite observar imagenes y descripciones del clima en tiempo real ademas de poder observar un pronostico del tiempo de los proximos 5 dias.

Este proyecto me permitió explorar el uso de APIs externas como las de openweather(Data sobre el clima y el pronostico) y Unsplash(imagenes de fondo), y cómo integrar información del mundo real en una aplicación web.

Además, pude practicar el diseño de interfaces responsive y la implementación de estilos modernos con Tailwind CSS, logrando un resultado limpio y funcional.

El Desafío

El desafio principal era poder manejar informacion dinamica en tiempo real, por lo tanto ,debía investigar y aprender sobre las apis que me podrian servir para obtener la informacion necesaria para el funcionamiento de la aplicacion y de esta manera poder aplicar estos conocimientos en el desarrollo de la misma. Asi mismo hacer que la aplicacion se sintiera dinamica y agradable para el usuario , implementar un buen diseño, fluido, moderno y que fuera acorde al proyecto.

La Solución

La solución fue investigar y aprender sobre las apis que me podrian servir para obtener la informacion necesaria para el funcionamiento de la aplicacion y que fuera data confiable.
